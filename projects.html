Bir geomatik mühendisi adayı olarak bu koyları yalnız birer gezi rotası olarak değil; karadan ve denizden ulaşım zorluklarını (sadece tekne, sarp falez patikası, 4x4 dağ yolu, kolay araç yolu) CBS ortamında modelleyerek sundum.

🎯 Sorun 1: Kıyı Marker Çakışması & Zoom Eşik Değeri

Problem: Türkiye kıyı şeridinde onlarca koy birbirine çok yakındır (Örn: Kaş veya Datça kıyıları). Türkiye genelindeyken (Zoom 5-6) tüm pinlerin gösterilmesi haritayı okunmaz bir karmaşaya çevirir.

Çözüm: Leaflet zoomend olay dinleyicisi ile haritanın anlık zoom seviyesi kontrol edilir. zoom >= threshold ise koy katmanı haritaya eklenir, değilse map.removeLayer() ile gizlenir.

// Leaflet Zoom Threshold Çözümü: const threshold = 7; map.on('zoomend', () => { if (map.getZoom() >= threshold) { if (!map.hasLayer(markersLayer)) map.addLayer(markersLayer); } else { if (map.hasLayer(markersLayer)) map.removeLayer(markersLayer); } });
🌍 Sorun 2: Uzaklaşınca Dünyanın Tekrarlamasını Önleme

Problem: Varsayılan Web Mercator projeksiyonunda karolar boylam boyunca sonsuz kez kopyalanır. Kullanıcı uzaklaştığında yan yana birden fazla Türkiye ve Akdeniz görür.

Çözüm: 1. L.tileLayer üzerinde noWrap: true tanımlanır.
2. Harita sınırları maxBounds: worldBounds ile kilitlenir.
3. Sürüklemeyi tamamen durdurmak için maxBoundsViscosity: 1.0 ve minZoom: 2 ayarlanır.

// Leaflet Dünya Tekrarını Engelleme: const worldBounds = L.latLngBounds([-85, -180], [85, 180]); const map = L.map('leaflet-map', { maxBounds: worldBounds, maxBoundsViscosity: 1.0, // Lastik etkisini kaldırır minZoom: 2 }); L.tileLayer(url, { noWrap: true }).addTo(map);

🎯 Sorun 1: OpenLayers Yerleşik minZoom Mekanizması

Problem: Yüzlerce kıyı noktasının küçük ölçeklerde çizdirilmesi GPU ve tarayıcı belleğini yorar.

Çözüm: OpenLayers, katman nesnesinin kendisine doğrudan minZoom: 7 özelliği vermeyi destekler. Böylece herhangi bir manuel olay dinleyicisine gerek kalmadan çizim döngüsünde filtrelenir.

// OpenLayers Katman minZoom Özelliği: const vectorLayer = new ol.layer.Vector({ source: vectorSource, minZoom: 7, // Zoom < 7 iken katman otomatik gizlenir style: myCustomStyle });
🌍 Sorun 2: OpenLayers wrapX: false ve multiWorld

Problem: Karo kaynakları varsayılan olarak sonsuz dünyalar çizer.

Çözüm: Karo kaynağına doğrudan wrapX: false parametresi geçilir ve harita görünümüne multiWorld: false verilir.

// OpenLayers wrapX Kapatma: const esriSource = new ol.source.XYZ({ url: 'https://server.arcgisonline.com/ArcGIS/rest/services/World_Street_Map/MapServer/tile/{z}/{y}/{x}', wrapX: false // Dünyanın yatayda tekrarlanmasını önler! }); const view = new ol.View({ center: ol.proj.fromLonLat([29.5, 37.2]), zoom: 7, multiWorld: false });
